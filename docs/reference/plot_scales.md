# Linear and log axes side by side

An example for the About tab: two made-up indices that grow at steady
rates, one doubling every year and one by 25% a year, on a linear axis
and on a log axis. On the log axis both are straight lines, and the
steeper line is the faster growth.

## Usage

``` r
plot_scales(mode = "light")
```

## Arguments

- mode:

  `"light"` (the default) or `"dark"`, to suit a light or dark page.

## Value

A plotly object.
